# Synthetic assessment benchmark v1

60 invented CVs across Node.js backend, AI/ML and Android internships, with Vietnamese, English and mixed-language coverage. Labels are curated design expectations against frozen sample JDs/rubrics; they are not independent HR labels or verified candidate competence.

The 36 development and 24 public-test cases are intentionally public and templated. Public test is a reproducibility set, not a protected holdout. Identity counterfactual pairs share a split/cluster. Exact references use production canonicalization/source spans; assessment input records contain no reference labels.

Do not infer hiring accuracy or population fairness from these fixtures. Manifest hashes freeze inputs, roles and labels; changing an annotation creates a new reviewed dataset version.
