# Synthetic runtime seeds

Optional Backend Python examples for local seed import and synthetic smoke tests. Users can enter their own JD and define a dynamic rubric; these files do not restrict supported roles.

- `jd-backend-python.vi.md`: example JD used by deployment smoke.
- `rubric-backend-python.v1.json`: unapproved rubric draft.
- `interview-question-bank.v1.json`: unapproved question-bank seed.

Moved from the retired MVP handoff bundle without changing their bytes. Seed imports still require normal workflow review/approval. Real CVs and applicant records never belong in this directory.
